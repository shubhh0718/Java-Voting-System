# Java Voting System

## 📖 Overview
A console-based voting system developed using Java. The application allows users to vote for candidates and displays election results.

## ✨ Features
- View Candidates
- Cast Vote
- View Results
- Display Winner
- Menu-driven Interface

## 🛠️ Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/shubhh0718/Java-Voting-System.git
   ```

2. Compile the project:
   ```bash
   javac *.java
   ```

3. Run the project:
   ```bash
   java Voting System
   ```
